ГОТОВАЯ ВЕРСИЯ С ОБЩИМ ВХОДОМ ЧЕРЕЗ SUPABASE

Замените в проекте:
- index.html
- app.js
- styles.css

Добавьте, если их еще нет:
- supabase-config.js
- supabase-setup.sql

Остальные файлы проекта, включая initial-data.js, оставьте без изменений.

Проверка:
1. Выполните supabase-setup.sql в Supabase.
2. Создайте пользователей в Authentication -> Users.
3. Откройте сайт в режиме инкогнито.
4. До входа должен отображаться только экран авторизации.
5. После входа откроется дашборд.
6. Кнопка «Выйти» находится в шапке.

Важно: anon key в supabase-config.js допустимо использовать в браузере. Защита данных обеспечивается политиками RLS из SQL-файла.
