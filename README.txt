Файл для деплоя

1. Замените текущий app.js файлом из архива.
2. Остальные файлы проекта не меняйте.
3. Обновите страницу через Ctrl + F5.

Сохранено:
- полноэкранный вход через Supabase;
- проверка и сохранение сессии;
- кнопка выхода;
- облачная синхронизация.

Добавлено:
- фиксированное соответствие занятий направлениям Сила, Гибкость и Йога;
- распознавание колонок Доступно записей и Всего записей.
