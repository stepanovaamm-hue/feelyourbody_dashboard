Файл для деплоя

1. Замените текущий app.js на файл из архива.
2. Остальные файлы проекта не меняйте.
3. После загрузки обновите страницу через Ctrl + F5.
4. Заново загрузите по одному актуальному отчету каждого типа.

Зафиксированные направления:

Сила:
- Плоский живот
- Сила + МФР
- Фитнес + растяжка
- Ягодицы 3D

Гибкость:
- Антиотечность / Антиотёчность
- Здоровая спина
- Индивидуальное занятие
- Мастер-класс
- Мышцы тазового дна
- Растяжка | stretching

Йога:
- Аренда
- Йога в гамаках
- Йога-нидра
- Хатха-йога

Авторизация Supabase сохранена.
